## 🧩 About

**Ragnarok Online Companion** is a curated list of Ragnarok Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, stat panel, minimap notes
- **Quality-of-Life Helpers** — inventory catalog, gear manager, overlay notes
- **Research Notes** — town layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Stat Panel — visible HP, SP, EXP and weight notes
- Minimap Notes — annotate town and field layouts for study
- Route Notes — record and review travel paths
- Movement Notes — observe walk and attack speed for study

### Wallhack
- Item Catalog — browse gear, cards, consumables and prices
- Custom Gear Notes — organize character loadouts
- Drop Table Notes — reference notes on monster drops

### Aimbot
- Field Notes — segment study on any map region
- Warp Notes — reference warp and portal positions
- Buff Timer Notes — track skill and potion timers in the panel
